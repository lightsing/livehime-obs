# Livehime OBS · Windows

一个在 OBS 里直接开播 B 站的插件。装好之后，你可以在 OBS 的「B站直播」面板里扫码登录、改标题、选分区、裁切上传封面，然后直接用 OBS 原生的「开始直播 / 停止直播」按钮开播下播——不需要再挂着哔哩哔哩直播姬，也不用额外跑本地转发程序。

> **安装要求**：Windows x64，**OBS Studio 33 或更高版本**。

---

## 安装与升级

### 推荐方式：直接用安装包

下载并运行 [0.4.6 Windows x64 安装包](https://github.com/lightsing/livehime-obs/releases/download/v0.4.6/livehime-obs-0.4.6-windows-x64-setup.exe)。

1. **安装前先退出所有 OBS 窗口**，避免插件文件被占用。
2. **老版本直接覆盖升级**：如果你之前装过 `0.1` 或 `0.2` 版本的安装包，直接运行新版安装器就行，不用先卸载，原本的安装目录和登录状态都会保留。
3. **选择 OBS 主程序目录**：指向包含 `bin\64bit\obs64.exe` 的文件夹（通常是 `C:\Program Files\obs-studio`），用来确认 OBS 版本。**注意：这一步选的是 OBS 本体目录，不是插件目录。**
4. **选择插件安装目录（仅首次安装）**：
   - 标准安装直接保持默认的 `C:\ProgramData\obs-studio\plugins\livehime-obs` 即可（需要管理员权限）。
   - 如果你用的是绿色便携版 OBS，或者只想装给当前用户，可以选到 OBS 自己的 `plugins\livehime-obs` 里。
5. **在 OBS 中打开面板**：启动 OBS，在顶部菜单「停靠窗口 / Docks」里勾选「B站直播」。如果点扫码登录时提示缺少组件，安装一下微软的 [Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 即可。

> **安装补充说明**
> - 安装包目前没有购买微软代码签名，如果 Windows 弹出保护提示，点「更多信息 → 仍要运行」即可。
> - 卸载只会删除插件本身的文件，不会动你的 OBS 场景、配置和账号缓存。
> - 通过 ZIP 安装且仍在使用 0.4.0 之前版本的用户，请先退出 OBS，再用 [0.4.6 便携 ZIP](https://github.com/lightsing/livehime-obs/releases/download/v0.4.6/livehime-obs-0.4.6-windows-x64.zip) 覆盖原目录。之后可在插件内自动更新。

### 自动更新

从 0.4.0 起，「B站直播」面板底部默认勾选「自动更新插件」。插件在 OBS 启动后检查，长时间运行时每 6 小时再检查一次。发现新版会在后台下载，无需安装 Node.js 或 npm，也无需登录 B 站。

更新就绪后，面板会显示新版本号。正常退出所有 OBS 实例后，安装向导才会打开；按提示完成安装，再启动 OBS。点「本次跳过」可以推迟安装。取消「自动更新插件」后，仍可手动检查、下载和选择「退出后安装」。

更新源是 npm 包 `@lightsing/livehime-obs-win32-x64`。插件优先访问国内 npmmirror，通过 npm 官方签名验证镜像中的版本和 SHA-512；镜像不可用、尚未同步或签名无法验证时回到 npm 官方源。安装前还会重新核对本地安装器的 SHA-256。

## 使用方法

### 1. 准备 OBS 推流设置

建议专门建一个给 B 站用的 OBS 配置文件，提前调好场景、分辨率和码率：

- 视频编码使用普通的 **H.264**，音频使用 **AAC**。
- **请关闭「增强广播 / 多轨视频」**，插件目前使用标准的单路 RTMP 推流。

### 2. 登录与开播

1. **扫码登录**：点击面板上的「扫码登录」，用 B 站手机 App 扫码确认即可。
2. **选分区**：分区分为「父分类」和「子分区」两个下拉框，登录后会自动选中你直播间当前的分区，子分区支持直接输入名称搜索。
3. **改标题**：最后一次输入后停顿 5 秒，插件会把完整标题同步到直播间。按回车、离开输入框或开始直播时会立即同步。标题下方显示保存状态。
4. **换封面**：鼠标移到当前封面上点「选择图片」，拖动和缩放调整成 **4:3** 画面后，点「保存并上传」即可自动裁切并上传。
5. **开始与停止直播**：直接点 OBS「控件」面板里原生的 **「开始直播」** 和 **「停止直播」** 按钮（插件面板里不单独放开播按钮）。
   - 开播前插件会先等标题和封面同步完，再自动向 B 站申请本场推流地址并开始推流。准备工作期间原按钮会变成「取消开播」，随时可以点它取消。
   - 如果遇到平台提示需要实名认证或人脸核验，按面板提示去官方网页完成认证，再回来刷新即可。
   - 下播时插件会等 OBS 停掉推流，再通知 B 站下播，并恢复你原本的 OBS 推流设置。

### 3. 开播途中的注意事项

- **请使用 OBS「控件」栏里的按钮开播**：OBS 快捷键、系统托盘菜单或其他插件的快捷开播，不会经过本插件的 B 站开播流程。
- **断网重连**：推流中途断线时，OBS 会自动重连同一场直播，不会重复申请开播。如果自动重连彻底失败了，点面板上的「重试 OBS 连接（当前场次）」即可。还没连上服务器时想取消，直接点「停止直播」。
- **先下播，再关 OBS**：请等确认下播成功后再退出 OBS。万一遇到 OBS 崩溃、强退或断电，下次打开软件登录后刷新一下房间状态，再点停止即可。**当前场次未结束前，不能退出登录或切换账号。**

## 超管提醒与实时面板

### 超管违规警告

只要已登录并连上自己房间的弹幕，哪怕你把互动面板关了、或者开启了鼠标穿透，收到平台的普通警告、整改提醒或切断通知时，OBS 都会直接弹出「提示」窗口并响起系统提示音：

- 有详情页面的提醒可以直接点链接在浏览器里打开。
- 点击「我知道了」只会关掉提醒弹窗本身，实际下播仍然使用 OBS 原生的「停止直播」按钮。

### 实时面板

插件自带 **「直播互动」**、**「房间观众」** 和 **「大航海」** 三个辅助窗口，可以从主面板按钮或 OBS 顶部「停靠窗口 / Docks」「工具」菜单打开。它们都支持拖到 OBS 边缘停靠、合并成标签页，或者拖出来当独立浮窗（OBS 会自动记住布局）。

- **直播互动**：上栏按到达顺序显示弹幕和礼物，下栏显示进场、关注、分享和点赞。上下拖动分隔线可调整两栏高度，重开后会恢复。互动窗口、进场历史和在线榜会随 OBS 当前主题换色。可以调字号、开关身份牌/勋章/头像、切换礼物币种、屏蔽不需要的分区，以及开启鼠标悬停暂停滚动。
  - 新弹幕、入场动态和打开「入场历史」后收到的新记录都会高亮。0.4.3 加强了整行渐变和左侧色条，高亮约 1.8 秒后淡出。
  - 向上滚动弹幕后，列表会保留阅读位置。新弹幕到达时，底部中央会显示「↓ N 条新弹幕」，点击即可跳回最新一条。连接中断时，面板顶部会用红色标出等待秒数或正在进行的重连次数。
  - 平台提供荣耀等级时，会在昵称前显示等级徽章。右击观众昵称或头像可以访问其 B 站空间。主播也可以在自己的房间拉黑观众、选择禁言 2、4 或 24 小时，或将观众设为普通房管。确认框会列出昵称和 UID，提交后显示平台返回的结果。
  - 插件会自动下载并显示收到的直播间表情。单独发送的表情以大图显示，夹在文字里的表情按原位置显示。图片加载时，表情名带有淡色底纹和点状下划线。加载成功后原位换成图片，加载失败或缺少图片地址时保留这个标记。动图显示首帧。关闭头像也可以看到表情。
  - 登录并加载房间后，在互动窗口底部输入文字，按回车或点「发送」即可发到当前直播间。发送失败会保留草稿并显示原因。
  - 点「入场历史」可查看本次连接收到的最近 500 条入场记录，按时间显示观众昵称。切换账号、房间或退出 OBS 时清空；同一房间短暂断线重连会保留。记录只存在内存里。
  - **礼物和弹幕**按到达顺序显示在同一列表。礼物行依次显示身份牌、昵称、“投喂”、礼物名和礼物图片。“投喂”使用柔和的主题强调色，礼物名使用随底色调整明暗的琥珀色。多件礼物会在图后标出数量。可在「显示设置」里切换「在弹幕中显示礼物」。
  - **鼠标穿透**：把「直播互动」拖成独立浮窗后可开启穿透。穿透时仍可点击弹幕输入框打字，按回车或点击「发送」即可发出弹幕，其他位置的点击会落到后面的游戏或应用。要操作整个面板，可以点「B站直播」主面板上的 **「解除互动穿透」**、从 OBS「工具」菜单解锁，或重新打开「直播互动」。停靠、关闭窗口或重启 OBS 也会解除穿透。
- **房间观众**：浮动时可单独开启「鼠标穿透」。从主面板或 OBS「工具」菜单重新打开「房间观众」即可恢复鼠标操作。支持切换在线榜（按贡献值/进房时间）和亲密榜，查看今日/昨日、本周/上周、本月/上月榜单。
- **大航海**：支持周榜、月榜、陪伴榜和翻页加载（翻到多页时为了不打断浏览，会暂停自动刷新，点手动刷新可回到最新第一页）。

窗口停靠后可继续压低高度。内容放不下时，用右侧滚动条访问其余控件。

把「B站直播」或实时面板拖成独立浮窗后，可以在浮窗里改标题或输入弹幕，OBS 主窗口会留在其他应用后面。OBS 主窗口在后台时，拖动插件浮窗不会触发自动停靠。要停靠，可以先将 OBS 主窗口切到前台，或使用面板上的「停靠到 OBS」。面板嵌在 OBS 里时，点击它会激活主窗口。

## 账号与隐私

- 扫码窗口使用独立的浏览器环境，不会读取你平时使用的浏览器或直播姬本地账号数据。
- 登录凭证加密保存在本机 OBS 插件配置目录中，点退出登录就会删除。
- 每次开播获取的推流密钥只在本次直播期间临时使用，不会写入 OBS 配置文件或日志里（**直播过程中请不要自己去 OBS 推流设置里点击保存**）。
